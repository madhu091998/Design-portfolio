# Design portfolio

A small static portfolio site. There's no build step: plain HTML and CSS.

- `index.html`: home page
- `contracts/`: the Contracts case study
- `play/`: Daring Dash, a tiny retro platformer (one self-contained HTML file)
- `assets/style.css`: shared styles
- `assets/contracts/`: case study images (recreated screens, fictional data)

## Preview locally

Open `index.html` in a browser, or run `npx serve .` and visit the printed URL.

## Publish with GitHub Pages

Settings → Pages → Deploy from a branch → pick the branch and `/ (root)`.
