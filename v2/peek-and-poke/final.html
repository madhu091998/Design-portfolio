Making UI changes without all the back and forth.

Tweak things visually, see what works, and pass the exact changes to Claude or Cursor.

The problem

Making small visual changes while designing in code was tedious. Even for something like spacing or colour, I'd guess a value, find the right design system token, prompt Claude or Cursor, and wait to see how it looked.

Most of the time, I didn't know the exact value I wanted. I just wanted to tweak things and see them change right away, without the prompt-and-check loop.

The solution

That's where Peek & poke came in. It's a lightweight, Figma-like inspector that lets me select elements on a live page and tweak spacing, colours and typography right on the UI.

I also made sure the properties in the inspector, like colours and typography, are mapped to our company's design system tokens. This way, designers can see and use the existing styles instead of having to remember them.

Once I'm happy with the changes, I can copy the generated prompt and pass it to Claude or Cursor to update the actual code.

Making design feedback a little less tedious.

Leave feedback directly on live pages and send everything to Figma, without the usual screenshot and annotation setup.

The problem

During design QA at Everstage, we'd take screenshots from Chrome, paste them into Figma, draw rectangles around the elements that needed changes, and add annotations for developers, like “Change this padding to 12px.” We'd then share the Figma file with them.

This whole process often took longer than adding the feedback itself.

The same happened when annotating edge cases in coded prototypes to explain behaviours and flows to developers.

The solution

So I added an Annotator to Peek & poke that connects Chrome and Figma. Designers can click any element on a live page, type or speak their feedback, add as many notes as needed, and click Send to Figma.

The screenshot lands in Figma with every annotation in the right place, without any of the manual setup.

Where it is now

What started as a small tool for my own workflow is now being used by other designers at Everstage too. It's been nice to see them finding it useful.
