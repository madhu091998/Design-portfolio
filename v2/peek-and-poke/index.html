Making it easier to design directly in code.

Peek & poke is a little browser tool I built to help designers turn UI changes into precise prompts for AI coding tools and send feedback from live pages to Figma.

01Element inspector

Point at the UI, get the exact change.

The problem
Asking an AI coding tool to “add more padding to this card” usually starts a back and forth. Which card? How much? Just this one, or every card like it?
The idea
Edit the element right on the page and see it change. Then copy a prompt that names the exact element, the new values, the design-system tokens and whether the change is for one card or all of them.

02Annotator

Feedback, pinned to the element.

The problem
Feedback on a live build usually means a screenshot, a paragraph explaining which button I meant, and then moving it all into Figma.
The idea
Click an element, type or say a note, and send everything to Figma with each note pinned to the element it’s about.
